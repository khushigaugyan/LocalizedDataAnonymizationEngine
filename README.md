# Localized Data Anonymization Engine

A privacy-focused tool that detects and anonymizes sensitive information from local files before sharing them.

## Problem
Users often need to share logs, documents, and datasets that may contain personal information. This project helps protect privacy by removing or masking sensitive data.

## Features
- Detect sensitive information
- Anonymize personal data
- Process local files securely
- Maintain data privacy

## Tech Stack
- Java
- Spring Boot
- Maven
